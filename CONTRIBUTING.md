# Contribuindo

1. Fork e clone.
2. Crie uma branch `feat/<assunto>` ou `fix/<assunto>`.
3. Rode `pytest` e `ruff check .` antes de abrir PR.
4. Abra PR com descricao clara e criterios de aceite.
5. CI deve estar verde antes do merge.

Sem segredos no Git. Dados de exemplo devem ser ficticios e sinalizados.
